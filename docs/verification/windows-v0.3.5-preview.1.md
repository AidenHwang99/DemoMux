## 手动卸载替代方案（用户 2026-11-09 授权调整）

用户接受快捷手动卸载入口作为自动卸载的替代。本轮交付不再承诺原生助手或自动自删除；原始计划保留作历史参考。

- 设置固定底栏提供「手动卸载 DemoMux…」，在同一设置窗口显示程序位置、数据位置、保留／清除选项及保护说明。底栏不随正文滚动。
- 「打开位置并退出 DemoMux」先生成独立 HTML 说明、启动外部查看器并通过 Windows Shell 定位程序目录及打开数据目录，再走既有正常退出流程，取消并等待当前操作，释放私有组件与说明窗口。任一定位失败则报错并保持应用打开。
- 明确由用户在 Explorer 送入回收站，不自动删除应用或持久数据，不注销云端账号或清空回收站。
- 核对包清单后才建议删除专用包目录。发现混放文件、空目录、修改文件、无效或缺失清单时明确保留／警告，不建议删除整个目录。包清单自身作为手动移除的元数据单列。
- 保留模式：仅建议清理 Components、Sessions、CaddyData、WebView2；保留整个 Tailscale 目录和 projects-v1.json。全清模式额外列出本机身份和偏好项，仍由用户手动处理。始终保护原始项目、外部服务、其他副本及系统组件。
- 独立说明使用当前用户专用 ACL，HTML 编码所有内容，不包含外部资源或脚本；拒绝将说明写入待清理的程序／数据目录。临时说明由用户最后手动删除，不宣称零残留。

- 下面的最终包桌面检查记录与外部清理验证须以本轮实际日志补充；此前的自动自卸载未覆盖记录不代表本轮手动入口有自动删除能力。

## 发布方式与兼容性改进（2026-11-09）

本轮按用户确认的「推荐入口＋高级检测」实施，保留手动卸载等已有改动，不修改 Mac、网关路径转发、TLS、DNS、身份校验或名额分配规则；未新增项目数据字段。

- 端口项目默认显示「独立入口（推荐）」和适用说明，子路径方式移入高级区域，提供返回推荐方式；取消原基础路径自我确认，复制操作明确仅复制配置路径。HTML 项目保留既有选择和发布行为。
- 本机预检只请求当前 127.0.0.1 端口，总体 8 秒、最多三次同端口且不越出目标前缀的跳转。根路径成功而项目路径 404 时在弹窗内解释并禁止发布。权限、服务不可用、超时、跳转越界等分别反馈，未知结果不能启用发布。
- 输入 400ms 防抖，模式或路径变更立即失效；会话版本阻止旧异步结果覆盖新选择；关闭时取消并丢弃结果。提交时只复用 30 秒内相同项目、端口、方式、路径的成功结果，过期重新检查，不提前占用名额。
- 成功文案仅承诺本机路径可访问，不把 SPA 任意路径的 200 当成资源／API／交互完全兼容。最终公网验证保留；项目 HTTP 错误保留数字状态码，路径 404 提供显式重新选择独立入口的恢复操作和会话内草稿。
