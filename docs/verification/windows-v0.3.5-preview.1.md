## 发现的问题与处理

1. 五步原实现按序号推断完成：改成独立状态，在真实操作成功处更新。尚需真实登录与公网链路验证。
2. 调整窗口宽度会重建底栏：移除 SizeChanged 重建，改成布局测量时重排子控件。通过往返 DIP 宽度自动检查。
3. Windows 原本打包 Mac 说明页：改为 Windows 专用源文件，两个入口共用。
4. 测试窗口锁定 DLL 导致 MSB3027：确认进程路径后正常关闭本次创建的隔离测试窗口，重新构建通过。原错误日志保留。
5. 新验收文件缺失导致首次打包停止：补齐本文件后重新打包。该构建不视作最终验收包。
