## 本轮发现并修复

1. 不同长度名称会使操作组横向漂移：为文本和操作组设置明确布局，补回归并再次观察。
2. 窄窗口底栏的使用说明按钮被拉宽：使用独立弹性间距，补最小宽度断言及桌面复核。
3. 组件启动失败只显示前段普通日志：优先提取最终错误原因。
4. 登录恢复中的 `NoState` 可能导致过早进入验证：等待账号同步，校验当前身份和设备域名，每次公网探测前后复核。
5. 介绍页的刷新说明与新菜单名称不一致：修正文案，并与离线 HTML 同步打包。

## 验收边界

- 本轮没有另一台干净 Mac、手机外部网络、重启开机验收，也没有不同真实账号的完整切换验收。三项目混合路由本轮由自动回归覆盖，真实浏览器本轮验证的是单个专用 HTML。
- 锁屏期间曾尝试独立后台验收脚本，未通过；已移出交付源码，不计入通过项。随后完成的已安装应用桌面及真实公网流程单独记录如上。
- 未测全部显示缩放、所有硬件或动画帧率。自动重试的短间隔与停止 / 恢复交互通过隔离可控故障测试；未人为破坏真实账号证书。
- “入口已验证”表示最近一次身份、公共 DNS、HTTPS 和路由标记检查通过，不是持续可用性监控。试用包没有 Apple Developer ID 签名及公证。
