## 根因与改动

原版 0.3.5 在实际桌面显示“此试用版需要 Apple 芯片和 macOS 26”并退出；源码使用 `majorVersion == 26`。应用包 codesign 校验正常，无证据需要卸载依赖。本版统一通过 `PlatformRequirements.supports` 判断最低系统 26；保留 arm64、LSMinimumSystemVersion=26.0 和构建 deployment target。使用本机 macOS 26.5 SDK 编译，在 27.2.1 实测。无需重新下载已有有效组件或重新授权。
