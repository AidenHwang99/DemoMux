# Windows 0.3.3 Preview 2 · 公网重试修复

本机 Windows 11 x64 / 200% DPI。问题是旧版公网校验一次失败即停在第五步，需要手动从头重试。本次实测本机页面、公网 DNS、直连公共 IP 和系统代理出口均能返回正确标记，但存在慢响应／间歇超时，不能将其认定为永久授权失败。

修复：超时、DNS 暂未就绪、连接失败与握手中断自动重试，等待 2、4、8 秒后保持 15 秒间隔。界面显示尝试次数、错误原因和逐秒倒计时，提供「停止重试」及停止后的「重新校验」。不重复下载或登录。停止不会视为验证成功；首次引导停止时撤下介绍页 Funnel，重新校验时仅恢复所需转发。发布中的取消仍回退名额。

证书错误、响应标记／跳转无效、账号变化不自动重试；每次网络尝试前后重新确认身份，不放宽 TLS、修改系统代理或绕过公网检查。

复测还实际遇到 EFS 状态写入返回 `ERROR_FILE_NOT_ENCRYPTED`，此前补丁只覆盖访问拒绝及跨设备错误。Tailscale `1.104.5-demomux.2` 补充该错误分支，仍仅允许同目录且加密、DACL 满足既有条件时回退。新组件在原正式授权目录启动 Funnel 并通过公网校验，未解密授权或放宽权限。EFS 内容与 DACL 专项通过；断电原子性边界沿用组件说明。

48 项回归通过，包括失败后成功、倒计时、等待中取消、请求中取消及不可重试错误；见 [日志](windows-v0.3.3-retry-regression.log)。EFS 专项见 [日志](windows-v0.3.3-retry-efs.log)。

隔离 UI 测试通过 `Tests --retry-ui` 注入超时，不启动 Caddy、Tailscale 或读取用户授权。真实转发路由的临时故障注入被自动审查阻止，未执行；不声称完成断网或外部设备测试。Win10、其他 DPI 和第二账号仍待测。

安装包与固定组件分别使用新标签发布，保留全部既有 Windows/macOS 版本。公开上传及重新下载比对由发布流程执行，最终记录以公开 Release 与本机复核为准。

实机隔离窗口已观察自动倒计时、停止后「未完成验证」及「重新校验」恢复。截图仅存本机 outputs/retry-countdown-fixture.png 和 retry-stopped-fixture.png。后续测试窗口增加显眼的隔离标识，未执行的前置步骤不再画作已通过。正式窗口已恢复真实账号并进入控制台，账号管理显示姓名、邮箱和网络；账号未同步／缺少预期身份时的门禁有自动回归。流光改为原生 TranslateTransform 动画，倒计时仅更新文字，动画不因每秒更新重启；不宣称对所有硬件量测达到 60 FPS。
