# Windows Preview 3 · 菜单与操作布局

用户截图明确暴露两个问题：更多菜单左侧灰色默认图标栏遮挡文字；项目操作以两排按钮堆叠，次要和停止操作争夺注意力。

修复使用完整 ContextMenu 模板，统一背景、菜单项、分隔线和滚动容器，移除系统图标沟槽。弹层与触发按钮右对齐，提供向下／向上两种放置位置；可用高度受工作区约束。保留键盘访问及清晰焦点。

已发布项目的「打开网页／复制链接／更多」同排对齐，复制为主要操作，取消发布与维护操作归入更多；不显示不可用的重新定位和重复的当前首页命令。未发布项目保持同一操作栏。状态和首页标签合并一行，链接截断后可查看完整提示。

顶部三种导入统一到「添加项目」菜单，底栏只显示当前可用的启动或结束操作；窄窗口采用两行底栏，保留固定操作区域。

Windows 11 x64、实际 200% DPI 验收：

- 隔离 `Tests --layout-ui` 创建发布、端口、文件夹及超长名称示例，不读取正式授权或修改用户项目。窗口有显眼隔离标识。
- 实际展开更多菜单，最终截图 `outputs/layout-menu-final.png`，文字完整，无灰栏覆盖；分隔线采用统一颜色与缩进。
- 菜单中修改名称能打开输入框并取消；添加项目菜单能打开端口表单并取消。
- 1440 × 1120 像素（720 × 560 DIP）下操作栏、长名称省略和底栏可见；内容可滚动，见 `outputs/layout-narrow.png`。
- 同时保留的正式实例与正在分享的项目在隔离验证阶段未修改。

48 项功能回归见本次日志。截图与菜单布局检查不能替代全部键盘、屏幕阅读器、Win10 或其他真实 DPI 验收；这些边界沿用前版。保留此前重试、同步身份门禁和 EFS 修复。
