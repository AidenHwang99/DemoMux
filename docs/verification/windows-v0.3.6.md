# Windows 0.3.6 验收记录

2026-11-10，Windows 10 22H2 x64，.NET 10.0.14。发行包为当前用户完整 EXE 安装器及便携 ZIP；两者都内置锁定组件。发布状态以 Release 为准，README 仅在公开回下载校验后更新下载入口。

## 已通过

- Windows 回归 208 项（原有 202 项与新增 6 项内置组件用例），包含真实本机 Caddy 路由、三项目混合分享、HTML、发布预检、托盘和 WPF 生命周期。
- 平台图标边界 5 项，Mac 应用源码和资源没有修改。
- 实际内置 Caddy 和 Tailscale 在下载地址不可达的情况下，从完整包成功准备，ZIP 及可执行文件哈希与锁文件匹配。损坏、缺失、取消均不会被当作成功，也不静默转为联网下载。
- 隔离安装 17 项：使用已校验的正式 0.3.5 解压目录构建旧版安装夹具，升级至 0.3.6；中文空格路径、当前用户注册、全部包文件 SHA-256、桌面和开始菜单快捷方式、重复安装修复、禁止降级（退出码 7）、运行互斥阻止安装（退出码 1）、卸载、注册与快捷方式清理、重装及外部原始文件保留。
- 安装版加载对应注册卸载器通过。真实桌面可访问性树读到中文安装向导、设置的「卸载 DemoMux…」和独立测试数据目录；测试夹具无真实账号或公网分享。
- 发布流程再次执行回归、图标边界、实际离线组件与隔离安装测试；缺少完整 EXE 不允许发布。公开后重新下载全部附件比对 SHA-256，再更新 README 直链并关闭发布开关。

本地证据：outputs/verification/installer-regression-final.log、offline-components.log、installer-smoke.log；隔离安装逐步日志位于 installer-DemoMux.Windows.Test-*。流水线日志与公开资产校验作为发行证据保留。

## 修复记录

- 首次启动将组件准备、哈希校验与私有服务启动分别显示；安装包内置组件避免组件下载受另一台机器网络影响。
- 安装升级保留既有数据，标准卸载只移除安装器管理的文件；应用正常退出后才启动卸载器，避免托盘偏好阻止卸载。
- 现有便携副本不被迁移或删除；安装前检查旧版进程及新版互斥量，不强制结束进程。
- 修复英文 Windows 上测试工具将中文快捷方式路径读成问号的误报：使用 IShellLinkW Unicode 接口读取真实目标，保留严格路径比较；加入发布前快速安装器检查，最终生产 EXE 在全新 CI 主机实际安装、修复、卸载及重装。
- README 下载块由发布脚本统一生成，CI 检查版本和安装包直链，避免之后只提供 ZIP 或挂未发布地址。

## 未覆盖及限制

- 当前桌面工具点击返回 coordinate input geometry is unavailable，截图分别返回 FrameArrived timed out 和 window capture timed out。已完成可访问性读取，未将其算作完整视觉、键盘交互或最终卸载按钮点击验收。
- Windows 11、物理多屏 DPI、实际磁盘不足／中断安装回滚、安装向导取消、真实公网持续分享及另一台 Windows 的现场网络仍需补测。
- 为保护正在运行的主副本和真实账号，未用正式生产入口连接真实身份；组件离线检查使用不可达下载地址，并未修改整机网络设置。旧版升级由隔离安装夹具验证，原有便携目录继续保留。
- 安装包当前未签名。标准卸载保留整个用户数据目录；如需彻底清除账号及偏好，应另行明确选择清理，不会连带删除云端账号或原始项目。
