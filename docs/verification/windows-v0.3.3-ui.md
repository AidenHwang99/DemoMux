# Windows 0.3.3 UI 预览版验收

日期：2026-11-08。基于已公开的 Windows 0.3.2，按用户提供的 Mac 主界面截图打磨 Windows 原生 WPF 应用。Mac 源码、标签和 0.3.2 公开包保持原样。

## 改动

- 沿用 Mac 的黑红色板、柔和背景、玫红主操作、编号区块、身份卡、项目列表和固定底栏；保留 Windows 标题栏与系统文件选择器。
- 统一按钮悬停、按下、禁用和键盘焦点；深色输入框、选择框、复选框、菜单、细滚动条及弹窗。
- 项目卡片突出预览／发布，将启动、停止、改名、重新定位与首页设置集中到「更多」。长名称省略并提供完整提示。
- 五步引导显示已完成、当前步骤和等待重试；操作中显示进度并可取消；错误支持重试，复制有结果反馈。
- 发布前展示预计链接，路径标识即时检查；端口项目复制基础路径并确认后才能按路径发布。改名和端口输入即时校验，危险账号操作先确认，默认焦点在取消。
- 支持 Ctrl+O、Ctrl+Shift+O、Ctrl+L、F5、Esc；快速预览按项目 ID 关联，重新定位端口后不会查找失效的旧端口记录。

## 实机与回归

Windows 11 专业版 x64 / 26100，真实 200% DPI（窗口 DPI 192），.NET 10.0.14。38 项功能回归通过，见 [日志](windows-v0.3.3-ui-regression.log)。

| 场景 | 实际结果 |
| --- | --- |
| 账号沿用和公网启动 | 真实账号无需再次登录；遇到现有网络间歇握手／响应超时，重试后验证通过 |
| HTML 公网分享 | 导入已有测试项目后，从新发布弹窗实际发布，显示 1 / 3；改名后保留链接，取消发布后释放名额 |
| 名称与端口表单 | 空名称和 8081 端口显示即时错误，确认禁用；输入有效值后恢复；本机 43123 HTTP 服务添加成功 |
| 发布方式 | 路径／独立入口切换更新链接和说明；端口路径模式未勾选确认时禁用发布，勾选后启用 |
| 更多菜单 | 实际启动、改名、重新定位与取消发布可操作；重定位端口后快速预览使用新地址，服务未启动时给出连接错误 |
| 账号管理 | 身份、连接和会话管理采用统一样式；暂停确认可取消，未进行新的第二账号登录 |
| 布局 | 同参考图 1840 × 1384 像素比较；最小 720 × 560 DIP 时底栏换行，内容可滚动，底栏操作可见 |

样式比较、修改记录和本机截图路径见仓库根目录 `design-qa.md`。截图包含真实账号信息，仅保留在本机 `outputs/`，不上传公开仓库。

## 边界

沿用 [0.3.2 验收边界](windows-v0.3.2.md)：未签名；Windows 10、独立外部设备网络、其他真实 DPI、真实第二账号等仍待测。新增快捷键在本版提供，但不将所有硬件键盘组合标记为实测通过。原生文件选择器的自动化在此次 UI 复测中受限；HTML 视觉测试使用既有测试目录，不能据此声称新一轮所有导入方式都已完整复测。

发布流程生成自包含 ZIP、固定 WebView2、中文说明、独立指南和校验文件，公开后重新下载比对。0.3.2 已单独完成公开下载及启动复核。
