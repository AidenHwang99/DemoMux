# Preview 4 · 共享图标与固定状态按钮

项目右侧保留固定五个槽位：预览／打开、复制、启动／停止、发布／取消发布、更多。按钮组在卡片右侧垂直居中，图标在 36 DIP 方形按钮中居中显示。外层动作均使用图标，保留中文 tooltip、无障碍名称和禁用提示。

启动与停止、发布与取消发布分别共用一个位置。以实际运行／分享状态决定图标，等待操作完成后更新；验证中保持发布图标并禁用。未发布时复制保持禁用占位，其他动作不因状态改变移动。停止项目仍撤下该项目分享，不关闭用户原有 HTTP 服务。

11 枚 Lucide SVG 原始文件已存入 `Shared/Icons/lucide/`，来源固定提交、SHA-256、完整许可及跨平台动作／尺寸映射同时存档，Windows 直接读取相同 SVG 进行原生矢量绘制。Mac 可按 `Shared/Icons/actions.json` 同步，未修改既有 Mac 应用代码或复制 Windows 字体。

Windows 11 x64 / 200% DPI 进行隔离布局检查；真实操作和公开包复核以本机记录及发布流程为准。49 项回归包含所有已收录 SVG 的原生解析。未覆盖的 Win10、其他真实 DPI 等边界沿用前版。
