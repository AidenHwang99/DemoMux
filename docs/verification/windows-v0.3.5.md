# DemoMux Windows 0.3.5 发行记录

日期：2026-11-10。版本：0.3.5。发行标签：windows-v0.3.5。渠道：正式 Release（prerelease=false）。

## 版本与来源

本版基于已整合至 main 的 Windows 最新开发成果，包含本机确认的发布预检、名称标识、系统托盘、设置布局、手动卸载及玫红图标。Mac 应用源码、ICNS、指南和共享 Mac 图源不变，两台主机继续从 origin/main 开发。

Windows 与 Mac 独立发布。正式发行是版本渠道选择，不代表全部设备、网络和原计划矩阵均已验证；以下分别记录已验证范围与未覆盖项。

## 验证范围

发布前已在本机全新隔离数据目录重跑并通过以下 202 项回归、5 项图标边界和 4 项原生托盘检查。原始日志为 outputs/verification/stable-0.3.5-regression.log、stable-0.3.5-brand.log 和 stable-0.3.5-tray.log；正式公开包还会由发布流水线重新测试和校验。

- 202 项 Windows 回归：名额与路由、真实本机 HTTP／Caddy、HTML／文件夹／端口混合项目、静态资源、错误与跳转、账号过渡状态、取消及重试、窗口布局与偏好、发布前检测、草稿及旧响应丢弃、手动卸载保护、托盘生命周期。
- 5 项跨平台图标生成边界测试：默认只更新 Mac，显式 Windows 使用其自有图源并同步文档，平台间资源不被隐式覆盖。
- 本机 Windows 10 22H2 隔离原生托盘检查：图标注册、关闭隐藏、恢复同一窗口和明确退出共 4 项；不使用真实账号或创建公网分享。
- 原生 EXE 图标提取、九档 ICO 和文档内嵌图像核对；完整包清单、ZIP SHA-256、独立 HTML、Markdown 图标和中文说明一致性检查。
- 发布流水线在正式标记前重新运行 Windows 与图标测试，按锁定版本重建和校验组件，生成安装包并上传所有附件；公开后回下载各附件核对 SHA-256，完成后才标为 Latest。流水线日志与 Release 附件 SHA256SUMS.txt 是该次公开包的交付证据。

既有测试环境：Windows 10 Pro 22H2 / 19045；CI 为 Windows runner。自包含 .NET 10，Caddy 2.11.9、Tailscale 1.104.5-demomux.2、WebView2 157.0.4341.42 继续按原锁定值，不随此版升级。

## 功能与保护

- 发布方式直接用下拉框选择；本机端口默认独立入口，路径方式先做本机检测。成功只承诺路径可访问，资源、API 和交互仍需浏览器检查。
- 名称提取英文和数字生成链接标识；已发布及自定义路径保持，变更旧链接需明确确认，发布失败保留原已保存路径。
- 关闭行为可选退出或托盘后台运行；默认关闭即退出。托盘明确退出及手动卸载入口始终真正退出并释放自有组件。
- 卸载为用户手动删除的快捷入口，不提供自动自删除；保护原始项目、真实账号、其他副本及系统组件。
- 未签名 ZIP 免安装包，不增加常驻服务或开机启动项。下载后先核对来源和 SHA-256，完整解压再运行。

## 已知限制和未覆盖项

- 完整视觉截图、物理多 DPI／多显示器、系统高对比度和透明选项切换仍未完成完整实测。
- 真实公网持续分享、独立访客网络、资源／API／WebSocket／完整交互尚需各项目自行验收；历史版本公网结果不自动作为本版通过证据。
- 托盘菜单人工点击、Explorer 重启、Windows 注销、第二实例完整唤回、最终生产包使用真实身份的桌面启动仍未全部实测。
- 本地 file:// 说明页浏览器预览被自动审批的 URL 策略拒绝；未绕过限制。文档图像及文件采用静态解码和打包一致性检查，不把这些检查称作浏览器视觉验收。
