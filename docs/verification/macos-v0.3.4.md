# DemoMux macOS 0.3.4 · 自适应布局、设置与卸载验收

2026-11-09 · 构建 10 · Apple 芯片 / macOS 26

## 改动

引导页的内容画布最大 1120 点，主界面最大 1200 点，均居中并留出边距。引导内容宽度不足 932 点时改成上下排布，五步卡改成横向条；宽窗恢复左侧步骤与右侧进度 / 身份。主界面的内容宽度达到 1060 点时，两组项目并排；不足时上下排列。项目卡片内容不足 660 点时，五个固定操作移到下一行。底栏根据当前可见按钮的实际总宽度切换一行 / 两行。

两页的滚动视口均在底栏上方结束，去除旧的覆盖式工具栏及固定底部补白。长错误完整换行，可滚动阅读。缩放只调整既有视图的方向和约束，不重建页面、重置校验或重启组件。

## 自动回归

`bash DemoMux/Tests/run.sh` 全部通过。见 [原始日志](macos-v0.3.4-regression.log)。

新增布局检查在 810 × 553、920 × 660、1000 × 575、1440 × 900、1920 × 1050 点内容尺寸之间切换并回缩；覆盖内容最大宽度和居中、底栏 / 视口不重叠、两栏断点、窄卡全部五操作、长诊断高度以及重试控件 / 流光对象保持不变。用一项分享与两项项目列表覆盖相邻列数量不等的情形。

原有三名额、路由、源文件、响应头校验、重试 / 身份、账号隔离和退出清理回归亦通过。

## 原生桌面

隔离 QA App 使用临时目录及合成账号，界面明确标示不登录、不连接公网。本轮实际操作包括：

- 默认窗口、系统放大，以及 810 × 553 / 1200 × 820 内容尺寸切换。
- 宽窗两组项目并排；窄窗恢复上下列表，名称省略、图标固定，底栏换行。
- 窄窗滚动到最后项目，完整卡片和底栏之间保留间距。
- 引导页宽窄重排时倒计时继续递增；小窗停止重试后显示未完成，身份卡可滚动到达。
- 中途发现单张卡片随另一列两张卡片被拉高，使用列尾弹性空间修复；补齐不等数量的回归后再次桌面确认。

## 设置与卸载

设置页与原有黑红字体、卡片、玻璃底栏保持一致，引导页、控制台与 ⌘, 均有入口。自动打开首页偏好迁入设置，增加窗口大小记忆、私有组件版本 / 下载状态 / 数据占用与隐去账号及源路径的诊断摘要。卸载入口固定于设置底栏，一次进入确认页，可勾选清除全部应用数据，或保留项目列表、本机登录和偏好。

自动检查覆盖 640 / 720 / 1200 点设置面板、底栏卸载按钮始终可见、偏好保存、诊断隐私、保留数据提示、退出卸载后不重写偏好。卸载模型使用临时 Home 与可恢复移动，测试全清 / 保留、旧版本组件、原始文件与系统程序保护、权限 / 偏好失败回滚、原位置冲突不覆盖、App 身份和符号链接边界。补充卸载等待取消期间 App 身份变化的失败回归，确认报错后保留状态监控、可继续演示；修复了提前关闭监控的问题。

原生界面中观察到偏好开关关闭后重新打开仍保持关闭，复制诊断显示反馈，保留数据选项与说明联动。另构建隔离 QA App，使用自己的真实运行 bundle、临时 Home 和独立偏好域，实际点击「停止并卸载」，通过 macOS 废纸篓 API 移走正在运行的 QA App 及私有样例数据，然后退出。结果见 [原始验收 JSON](macos-v0.3.4-uninstall-native.json)：六项均为 true，包含 App 与数据移除、进程停止、原始 HTML / 独立系统样例保护和实际安装 App 仍存在。没有对用户的实际 DemoMux 执行卸载，也没有清空废纸篓。

- [设置与复制反馈](macos-v0.3.4/settings.png)
- [卸载确认界面](macos-v0.3.4/uninstall-review.png)

卸载过程中移走的是可恢复的文件，不是安全擦除；Tailscale 在线账号和云端设备记录不会自动删除。目录权限失败会显示原因并尝试恢复，不提权、不移除外部系统服务。

## 实际安装版启动

布局版安装后在原账号完成五步检查进入 0 / 3 控制台；第五步曾出现握手中断，自动重试后成功。已观察其宽屏与缩回默认窗口的真实界面，没有发布或修改原项目。最终含设置的安装版已通过 ⌘, 打开设置，显示 0.3.4、固定组件状态与数据占用；卸载入口始终位于底栏。没有对真实安装点击卸载。见 [已安装版设置截图](macos-v0.3.4/installed-settings.png)。

## 打包检查

Swift 发布构建映射源文件前缀，并排除仅供开发使用的源码图标回退，避免在分发二进制中保留开发目录。发布前核对版本 / 构建号、App 与进程保护组件签名、11 枚 SVG、独立 HTML / 首次使用一致性、私有数据排除及 ZIP 校验值。
