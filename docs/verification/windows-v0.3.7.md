# Windows 0.3.7 验收记录

本轮针对使用本地域名路由的 HTTP 服务。2026-11-12 在 Windows 10 22H2 验证，已正式发布，下载与哈希见 [交付校验](windows-v0.3.7-publication-2026-11-12.md)。

## 已验证

- 真实 `console.localhost:8080` 通过带主机名的连接检查和独立入口预检。在隔离数据目录保存并重读项目，预览地址一致，旧目录备份内容一致。Edge 打开原地址并加载同源脚本。
- 真实项目从根路径 `/assets/` 加载脚本和样式。按项目名预检报告越界并保留独立入口选项。
- 隔离双主机样例由实际 Caddy 运行，两种入口分别加载各自的页面、脚本、样式和 API。Edge 实测两种入口的相对跳转，在网络请求发送前捕获两种绝对跳转的目标。Caddy 回归核对 HTTPS 地址、端口、状态码、路径和查询参数。
- 225 项 Windows 回归与 5 项图标边界检查通过。回归覆盖旧端口输入、无效地址、同端口主机区分、超时、不可达、循环、跳转及路径边界、HTML 检查大小上限与预检结果过期。

- 本机隔离安装检查 19 项通过，覆盖 0.3.6 升级、全部安装文件校验、快捷方式、修复、禁止降级、卸载和重装。正式发布流程在独立 CI 环境中安装最终 EXE，17 项验证通过。

## 覆盖边界

真实 8080 项目用于本机测试。公网路由与校验使用隔离样例验证，未验证真实 Funnel 公网访问。脚本动态生成的 URL、Cookie 域、外部认证和 API 仍由项目适配并通过浏览器验证。Windows 11 物理设备与多屏未实测。
