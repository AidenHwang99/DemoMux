# 0.3.2 平台功能对照

Mac 固定基线：macos-v0.3.2。Windows 0.3.2 以试用版交付，下面分别记录实现与实测；未覆盖项不计通过。

| 功能 | macOS 基线 | Windows 实现及验证 |
| --- | --- | --- |
| 原生主窗、黑红主题、身份卡与项目列表 | AppKit | WPF、原生标题栏、管理账号窗口与固定底栏；真实窗口及 200% DPI 观察通过 |
| 五步连接引导 | 已有 | 默认 AppData 目录真实登录、Funnel、公共 DNS 与 HTTPS 验证通过 |
| HTML、文件夹、HTTP 端口 | 已有 | 三种项目同时公网发布，文件夹资源和浏览器 JavaScript 执行通过 |
| 三名额与独立入口分配 | 已有 | 实现并回归通过 |
| 首页接管与切换、介绍页恢复 | 已有 | Caddy 原子重载回归通过 |
| 项目保存、改名与重新定位 | 已有 | 版本化 JSON、真实快照更新、源失效、改名和重新定位后链接保持通过 |
| 账号添加、切换、授权、暂停、退出 | 已有 | 私有管道、真实身份、授权、暂停恢复通过；第二账号和退出再授权待测 |
| 公共 DNS、TLS、响应头标记、严格跳转 | 已有 | 真实公网、错误跳转拒绝、取消和慢页面通过；证书及身份错误有回归 |
| 内嵌离线说明 | WKWebView | 固定 WebView2 随包，停止组件后打开、关闭释放资源通过 |
| 异常退出清理 | Supervisor | Job Object；真实 GUI 强杀后自有组件与包内 WebView2 均退出 |
| 兼容目标 | macOS 26 / arm64 | Windows 10 22H2、Windows 11 / x64；目前仅 Win11 26100 本机 |

最终验收以 [Windows 记录](verification/windows-v0.3.2.md) 为准。
