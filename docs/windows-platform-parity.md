# Windows 平台功能对照

## 0.3.5 Preview 1 开发现状（2026-11-10）

Windows 最新源码已整合至 `main`，版本 0.3.5-preview.1，发布开关关闭。Mac 与 Windows 主机统一使用最新 origin/main；旧 Windows 开发分支保留作历史。完整结论见[开发验收](verification/windows-v0.3.5-preview.1.md)、[主分支整合](verification/windows-main-integration-2026-11-10.md)和[跨主机协作](development.md)。

| 功能 | Windows 实现 | 当前验证范围 |
| --- | --- | --- |
| 设置与布局 | 偏好、组件、存储、受限诊断、固定底栏、右侧按钮及窄窗换行 | WPF 布局和偏好回归；完整截图、物理多 DPI 待测 |
| 关闭与后台运行 | 可选关闭即退出或隐藏到原生系统托盘；明确退出清理组件 | 生命周期回归和本机原生托盘 4 项检查；真实公网持续性、菜单点击和 Explorer 重启待测 |
| 发布方式及名称 | 下拉框选择路径／独立入口，按 Mac 规则提取英文和数字，保护旧链接 | 路径预检与草稿、超时／权限／404、混合名额和静态项目回归 |
| 手动卸载 | 用户确认采用手动入口、离线说明、目录定位和退出 | 隔离回归及部分桌面流程；不提供自动删除或宣称原生自卸载通过 |
| 图标与使用说明 | Windows 程序、窗口、托盘、指南页头／favicon、Markdown 采用同源玫红图标 | ICO 帧、HTML 内嵌图像、包清单散列核对；浏览器视觉预览受限 |
| 回归与发布 | 保留既有 Windows EFS、私有账号、Job Object 和网络校验实现 | 202 项本机与 CI 回归通过；尚未发布开发版 Release |

## 0.3.2 历史对照

Mac 固定基线：macos-v0.3.2。Windows 0.3.2 以试用版交付，下面分别记录实现与实测；未覆盖项不计通过。

| 功能 | macOS 基线 | Windows 实现及验证 |
| --- | --- | --- |
| 原生主窗、黑红主题、身份卡与项目列表 | AppKit | WPF、原生标题栏、管理账号窗口与固定底栏；真实窗口及 200% DPI 观察通过 |
| 五步连接引导 | 已有 | 默认 AppData 目录真实登录、Funnel、公共 DNS 与 HTTPS 验证通过 |
| HTML、文件夹、HTTP 端口 | 已有 | 三种项目同时公网发布，文件夹资源和浏览器 JavaScript 执行通过 |
| 三名额与独立入口分配 | 已有 | 实现并回归通过 |
| 首页接管与切换、介绍页恢复 | 已有 | Caddy 原子重载回归通过 |
| 项目保存、改名与重新定位 | 已有 | 版本化 JSON、真实快照更新、源失效、改名和重新定位后链接保持通过 |
| 账号添加、切换、授权、暂停、退出 | 已有 | 私有管道、真实身份、授权、暂停恢复通过；第二账号和退出再授权待测 |
| 公共 DNS、TLS、响应头标记、严格跳转 | 已有 | 真实公网、错误跳转拒绝、取消和慢页面通过；证书及身份错误有回归 |
| 内嵌离线说明 | WKWebView | 固定 WebView2 随包，停止组件后打开、关闭释放资源通过 |
| 异常退出清理 | Supervisor | Job Object；真实 GUI 强杀后自有组件与包内 WebView2 均退出 |
| 兼容目标 | macOS 26 / arm64 | Windows 10 22H2、Windows 11 / x64；目前仅 Win11 26100 本机 |

最终验收以 [Windows 记录](verification/windows-v0.3.2.md) 为准。
