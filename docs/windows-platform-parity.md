# 0.3.2 平台功能对照

Mac 固定基线：macos-v0.3.2。Windows 当前为开发验收中，代码具备不等同于实机通过。

| 功能 | macOS 基线 | Windows 实现及验证 |
| --- | --- | --- |
| 原生主窗、黑红主题、身份卡与项目列表 | AppKit | WPF、原生标题栏；首次引导已观察，完整控制台待验收 |
| 五步连接引导 | 已有 | 已实现；实机进入登录，公网待用户授权 |
| HTML、文件夹、HTTP 端口 | 已有 | 已实现；快照和资源回归通过，三种公网混合待测 |
| 三名额与独立入口分配 | 已有 | 实现并回归通过 |
| 首页接管与切换、介绍页恢复 | 已有 | Caddy 原子重载回归通过 |
| 项目保存、改名与重新定位 | 已有 | 版本化 JSON 实现；完整 GUI 测试待完成 |
| 账号添加、切换、授权、暂停、退出 | 已有 | 私有命名管道与 UI 实现；真实往返待授权 |
| 公共 DNS、TLS、响应头标记、严格跳转 | 已有 | 实现；标记和跳转回归通过，真实公网待测 |
| 内嵌离线说明 | WKWebView | 固定 WebView2 随包，真实文档加载已观察 |
| 异常退出清理 | Supervisor | Job Object；子进程释放回归通过，完整强杀待测 |
| 兼容目标 | macOS 26 / arm64 | Windows 10 22H2、Windows 11 / x64；目前仅 Win11 26100 本机 |

最终验收以 [Windows 记录](verification/windows-v0.3.2.md) 为准。
