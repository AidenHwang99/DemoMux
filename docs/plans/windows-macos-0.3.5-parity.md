# DemoMux Windows 同步 Mac 0.3.5 执行计划

日期：2026-11-09；状态复核：2026-11-10。执行对象：Windows 电脑上的开发代理或工程师。状态：Windows 开发功能已实施并完成部分验证，最终桌面与公网验收仍未完成，尚未发布。

执行范围已按用户后续要求调整：自动自卸载由快捷手动卸载入口替代；增加发布方式下拉框、本机路径预检、名称标识、可配置托盘、设置布局与新图标。以下原始需求保留作基线，现状以[开发验收记录](../verification/windows-v0.3.5-preview.1.md)及[同步复核](../verification/windows-sync-2026-11-10.md)为准。当前 202 项自动回归、隔离原生托盘检查通过，不能据此认定全部计划验收通过。

用户 2026-11-10 进一步明确要求把本机最新成果整合到 main，作为 Mac 与 Windows 后续工作的共同基线；旧工作分支名仅用于追溯原计划。[主分支整合记录](../verification/windows-main-integration-2026-11-10.md)和[协作说明](../development.md)记录实际入口与验证边界。

本任务需要在 Windows 主机完成开发、桌面操作、测试、发现问题、修复、复测、打包及 Git 更新。不能用 Mac 上的构建或隔离窗口代替 Windows 实机验收。

- 工作分支：`windows/macos-0.3.5-parity`。目标版本：`0.3.5-preview.1`；发布标签：`windows-v0.3.5-preview.1`。
- 用户已选择继续使用 ZIP 免安装包加应用内卸载，不增加安装向导，不注册系统卸载入口。

## 2. 界面与设置

### 2.1 自适应排布

沿用当前黑红色板、共享 SVG、圆角卡片和系统字体。Windows 11 保留现有窗口材质；Windows 10、关闭透明效果或高对比度时使用清晰实色回退。不新增终端用户字体或 UI 运行库。

全部断点按可用内容宽度及 WPF DIP 计算，不按物理像素或整个窗口宽度。

| 区域 | 规则 |
| --- | --- |
| 引导页 | 内容最大宽 1120 DIP，居中；内容不足 932 DIP 时使用横向五步条与上下详情，否则使用左步骤、右进度及身份 |
| 主界面 | 内容最大宽 1200 DIP；内容达到 1060 DIP 时，两组项目并排，否则上下排列 |
| 项目卡片 | 卡片内部不足 660 DIP 时，固定五操作移至下一行并靠右；顺序、36 DIP 点击区、18 DIP 图标、禁用占位保持 |
| 标题与底栏 | 窄窗允许状态独立成行；底栏按实际可见操作宽度换行 |
| 滚动 | 视口在底栏上方结束，最后一项不被覆盖；不同列数量不等时不拉高另一列单卡 |

保留主窗口最小尺寸 720 × 560 DIP。小窗可滚动访问全部内容。缩放只改变既有布局，不通过整页 Render 重建控件，不重置重试次数、动画、输入、焦点或项目状态。

### 2.2 五步事实状态

将步骤显示改为独立的待执行、进行中、已完成、已停止、失败状态，不能仅由 setupStep 序号推算成功。完成状态必须对应真实组件、账号、Funnel 和公网检查。恢复第五步校验时复用有效前置结果，身份变化则失效相关步骤。

保留现有退避、倒计时、停止和恢复、错误分类、探测前后身份校验，不重写已验证的 Windows 网络实现。保留三项目混合发布、独立入口、首页接管、账号切换、重新定位、更换端口及退出清理。

### 2.3 设置窗口

引导页和主界面底栏加入设置，增加 Ctrl+,；未完成下载、未登录或公网失败时也能打开。窗口、按钮、菜单、反馈均沿用同一主题。

设置包括：

- 演示偏好：公网就绪后自动打开首页，沿用现有 OpenHome 值；记住主窗口大小默认开启，保存正常窗口范围和最大化状态，按当前显示器工作区及 DPI 恢复，避免窗口落在已断开显示器外。说明无开机自启、退出停止私有组件。
- 组件与存储：展示固定版本、下载状态、私有目录实际占用、真实数据路径，提供打开数据文件夹和复制路径。按 Windows 实际内容说明 Components、projects-v1.json、Tailscale\PrivateState、CaddyData、Sessions、WebView2，不能照搬 Mac 文件名。
- 数据目录入口：使用 Windows Shell API 定位实际内容，优先选中 Components，没有组件时定位现有数据项，空目录直接打开。不要拼接 cmd.exe 命令。目录缺失、不可访问、打开或复制失败必须有反馈，不能把读取失败提示成没有数据。实际观察 Explorer 的内容是否可见，不能只看调用返回值。
- 支持与诊断：复制应用版本、Windows 构建、架构、组件版本、连接状态及发布数量；排除账号、邮箱、授权 URL、公网域名、项目名称、源路径和登录状态内容。离线使用说明继续可用。
- 应用维护：卸载 DemoMux… 固定在设置底栏，进入同窗口的确认页，只进行一次应用内确认。

现有项目、标识、账号授权、入口历史和 OpenHome 保留；新增窗口偏好以可选字段兼容旧数据，不重置目录。拆分可测试的 UninstallContext、UninstallPlan、执行结果和恢复接口，界面不直接递归删除。

生产自动卸载仅接受标准且确认归属的路径；隔离测试通过测试构建显式注入上下文。不得因 DEMOMUX_DATA_DIR 等环境变量而扩大生产卸载范围；遇到未能确认归属的自定义数据目录，停止自动清理并说明位置。

## 3. Windows 内置卸载

### 3.1 范围与确认

确认页展示实际将清理和保留的项，主按钮为停止并卸载。

- 移除当前应用副本的已确认包文件，包括随包 .NET 和固定 WebView2；移除 DemoMux 下载的各版本 Caddy 与 Tailscale。
- 清理本次会话快照、组件运行数据和 WebView2 缓存。
- 默认勾选同时清除项目列表、本机登录和偏好设置。取消勾选时保留项目记录、Tailscale 授权与设备身份、偏好和窗口配置；重新解压后重新下载组件。
- 原始 HTML、项目文件夹、外部项目进程、其他 DemoMux 副本、系统独立的 Tailscale/Caddy/Edge/WebView2/.NET 均保留。
- 不删除 Tailscale 在线账号，不自动删除云端设备记录，不清空回收站。

### 3.2 免安装目录保护

ZIP 可能与项目文件混放，不能递归删除 AppContext.BaseDirectory。构建时生成带相对路径和校验值的包文件清单，仅处理确认归属的文件；目录为空才移除。非包文件、用户修改文件和原始项目保留，并列出保留项。拒绝根目录、用户主目录、路径越界、目录联接和重解析点扩大范围，不跟随链接清理外部目标。

### 3.3 独立维护助手

新增静态链接的原生 x64 助手，随 ZIP 提供，使用 Windows 自带 API。开发和 CI 增加 MSVC/Windows SDK 构建步骤，不增加用户运行环境要求。

固定顺序：

1. 校验路径、归属、权限和助手完整性，生成不可变计划。
2. 取消并等待下载、登录、发布操作结束。
3. 撤下分享，停止自有组件，关闭说明窗口并释放 WebView2。
4. 将助手复制到应用和数据目录外的私有临时目录，完成启动握手。
5. 确认助手能够独立继续运行后退出主程序。
6. 助手等待主程序及已确认的私有进程释放文件，再执行清理。

助手不能使用管理 Caddy/Tailscale 的 ChildProcess 封装，不能放宽现有 Job Object 保护。无法建立独立运行条件时，主程序保持可用并报错，不直接退出。维护期间避免新实例重建正在清理的数据；不按进程名批量结束系统服务。

Windows 进程脱离 Job 有限制，不能假定启动标志总能解决：https://learn.microsoft.com/en-us/windows/desktop/ProcThread/process-creation-flags

### 3.4 可恢复清理

先在各目标所在卷创建当前用户专用恢复区，按计划移动并记录原位置，避免跨卷破坏 EFS 与 ACL。全部移动成功后，通过 IFileOperation 请求送入回收站，启用回收与遇错即停，逐项检查结果和中止状态；禁止自动降级为永久删除。无法确认可回收时中止并恢复。

失败时尝试恢复，不覆盖原位置新文件，列出已恢复项、回收站项及未恢复位置。主程序尚未退出时失败，应保留状态监控、允许继续演示；已退出后由助手展示结果、重试和恢复位置。助手临时文件清理失败时列出残留，不能虚报零残留。不留下常驻进程、任务或开机项，不自动提权、不关闭安全软件，也不因自身文件锁要求重启电脑。

Windows API 参考：

- https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags
- https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperationprogresssink-predeleteitem


保留现有用例，新增设置、布局和卸载覆盖。当前文档存在 48/49 项计数差异，以实际输出更新，不沿用旧日志或旧数字。

| 类别 | 必测场景 |

| 布局 | 720/810/920/1000/1440/1920 DIP 与回缩；最大化恢复；长名称、链接、错误；一列单项另一列多项；最后一项及底栏不遮挡 |

| 卸载 | 正在运行的隔离副本真实自卸载；全清/保留；说明打开、发布中、下载中、重试中卸载；文件占用、权限失败、回收站不可用、EFS、联接、恢复冲突、混放文件、多副本保护 |

卸载测试使用隔离应用副本和独立数据目录，验证原始 HTML、外部本机服务、系统 Tailscale 和正在使用的主副本保留。不得为测试卸载用户主副本或注销真实账号。

真实公网需要公共 DNS/严格 HTTPS 检查和默认浏览器页面资源、脚本交互。手机外网、第二真实账号、Windows 10 或其他 DPI 没有设备或授权时列为未覆盖，不写成通过；涉及新的个人登录或授权时交给用户完成。
