# DemoMux Windows 0.3.2 · 试用版

日期：2026-11-08 · 标签：`windows-v0.3.2`。以 `macos-v0.3.2` 为固定基线，保留 WPF 和 Windows 标题栏；macOS 版本未修改。

## 功能

- 五步引导准备 Caddy、Tailscale、登录、启用 Funnel、验证公网介绍页；每次打开重新验证，项目手动发布。
- 导入单 HTML、带资源文件夹和已运行的本机 HTTP 服务；保存项目，支持预览、启动、重启、停止、改名、重新定位和会话端口。
- 路径与独立入口共用三个名额，验证中预留，失败或取消后释放。独立入口按 8443、10000、443 分配，保留旧入口复用提示。
- 首项接管公网首页，支持切换首页，项目链接保持；撤下全部后恢复介绍页。
- 私有账号身份和网络展示；添加、切换、重新授权、暂停、退出；切换前撤下分享。
- 公共 DNS、严格 HTTPS、响应头标记和跳转范围验证；收到响应头后结束检查，不等待整页。
- 黑红色主题、身份卡、项目列表和固定底栏；原样复用 Mac 介绍 HTML，使用随包固定 WebView2 离线阅读。
- `%LOCALAPPDATA%\DemoMux` 保存版本化项目和偏好；备份迁移旧端口，保留私有授权；私有命名管道、Job Object 和进程归属检查，不安装常驻服务或开机启动项。

## 实机修复

修复账号刚登录的空用户状态、Windows 后端随 CLI 退出而复位、EFS 用户目录的组件安装和 Tailscale 状态写入，以及极小首块正文引发的代理响应头缓冲。待验证名额及时显示并在取消后释放，重新定位清理旧快照。

组件：Caddy 2.11.9、Tailscale 1.104.5-demomux.1、WebView2 157.0.4341.42 x64；.NET 10 自包含。Tailscale 是固定上游源码的 Windows EFS 兼容构建，来源、补丁、校验值和许可随组件提供。

## 验收与限制

Windows 11 专业版 x64 / 26100 本机实测：三种项目同时发布、第四项拦截与补位、资源、首页、快照、重新定位、账号暂停恢复、取消、错误跳转、慢页面、说明和退出清理通过；38 项自动回归与 EFS 专项通过。

仍未覆盖 Windows 10、第二台干净设备、100% / 125% / 150% 真实 DPI、真实第二账号、撤销授权及手机外部网络。当前网络存在间歇 DNS / HTTPS 超时，可重试；不绕过证书验证。EFS 的 Tailscale 状态回退不能保证突然断电时的原子性。

此包未签名，适用 Windows 10 22H2 / Windows 11 x64 兼容目标；微软运行时官方支持范围及实际覆盖分开说明。完整记录见仓库 `docs/verification/windows-v0.3.2.md` 或 ZIP 内「验收记录.md」。

下载后校验 `DemoMux-Windows-x64.zip.sha256`，完整解压到本机文件夹再打开 `DemoMux.exe`。无需另外安装 .NET、WebView2、Node.js、Python 或系统 Tailscale。首次登录与 Funnel 授权由你在网页完成。
