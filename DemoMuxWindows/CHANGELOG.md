# DemoMux Windows 0.3.2（开发验收中）

基线：`macos-v0.3.2` / `ee885d44b44c2ef40f3b2bfd54f29b5a10ce52b3`。

- 增加单 HTML、带资源文件夹、已运行 HTTP 端口的持久化项目目录；启动和重启静态项目生成快照，排除隐藏项与重解析点。
- 路径和独立入口共用三个发布名额，验证期间预留，失败或取消后释放。独立入口按 8443、10000、443 分配。
- 增加项目预览、重启、停止、改名、重新定位和本次会话端口；首页接管及切换，取消全部发布后恢复介绍页。
- 增加私有实例账号身份与网络展示、添加、切换、重新授权、暂停与退出；切换前撤下分享。
- 使用公共 DNS 返回的最多四个 IPv4 入口并发验证，严格检查 HTTPS、响应头发布标记与跳转范围，避免下载整页。
- 原生 WPF 黑红色界面保留 Windows 标题栏，内嵌说明使用随包固定 WebView2 157.0.4341.42 x64。
- 数据采用版本化 JSON 和原子替换；旧端口配置备份迁移。保留 Job Object、私有命名管道及进程归属验证。
- Windows 网关使用 Caddy 原子重载，更新单个项目无需重启其他入口。

实机发现并处理：Tailscale 上游 Windows 服务目录权限逻辑会同时设置所有者和主组，在本机普通桌面进程中返回拒绝访问。新建 PrivateState 子目录，显式应用仅当前用户、SYSTEM、管理员可访问的受保护 DACL，不修改所有者和主组，并迁移旧私有状态文件。

本版本尚未创建公开标签或 GitHub Release。公网授权、完整验收及公开附件校验未完成，详见 [验收记录](../docs/verification/windows-v0.3.2.md)。自包含分发包仍未签名。
