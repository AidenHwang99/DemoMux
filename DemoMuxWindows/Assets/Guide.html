DemoMux
使用指南 · 0.3.5
本机项目 · 公网演示

认识 DemoMux

把一个 HTML 或正在运行的本机项目，变成可以分享的 HTTPS 链接。同时发布最多三个项目。

01

请求怎么到达你的项目

  1. 来源HTML 或本机 HTTP导入静态页面，或指定已启动项目的端口。
  2. 路由Caddy提供静态文件，并把请求送到正确的项目。
  3. 公网Tailscale Funnel在你的 Tailscale 域名上提供 HTTPS 入口。
  4. 访问访客浏览器打开你分享的链接，查看对应项目。
02

准备一场演示

先验证公网介绍页

应用会按五步检查 Caddy、Tailscale、账号、Funnel 和公网入口。用自己的账号登录并启用 Funnel，公网检查通过后即可进入控制台。未同步账号不会进入公网校验。

预览，再发布

拖入单文件 HTML，或导入带资源的文件夹。项目已在本机运行时，可以直接添加 HTTP 端口。

先选择适用的发布方式

在「发布方式」下拉框选择「按项目名发布」或「使用独立入口」。本机端口默认推荐独立入口，通常无需修改项目。按项目名发布会提取名称中的英文和数字，例如 teleConnect_AI主动模式原型_155 生成 teleconnect-ai-155，也可手动编辑或点击「按项目名生成」。未发布的自动标识随改名更新，已发布或自定义路径保持；更改已发布路径需明确确认。

本机服务使用路径方式时，必须支持 /p/项目标识/；会先检查该路径，失败解释原因并提供改用独立入口。复制配置路径不会自动修改项目。静态 HTML 继续使用相对资源路径或独立入口。本机检测成功仅表示路径可访问，资源、API 和交互仍需浏览器验证；发布后还会进行公网校验。

演示结束后撤下链接

可取消单个项目的发布，也可停止全部。HTML 文件有更新时，在「更多操作」中选择「重新启动项目」刷新预览内容。应用退出后，其转发组件会随之关闭。

项目接管公网首页

首个项目发布后，原介绍页入口自动转向它。可用「设为首页」更换目标，各项目链接保持不变；有项目发布时，介绍页内容不再对外提供。

说明始终在 App 内

控制台的「使用说明」打开内嵌 HTML，停止服务后仍能阅读。没有项目发布时，公网介绍页恢复用于连接检查。

03

账号与公网

看清正在使用的身份

控制台显示实际连接的 Tailscale 账号和所属网络。「管理账号」可添加、切换或重新登录，独立于系统 Tailscale。

切换后，手动选择项目

各账号共用项目列表。切换前撤下旧分享，切换后只验证介绍页；要展示哪些项目，由你决定。

暂停会保留登录

暂停演示或退出应用会停止其转发组件。账号授权保留，下次可继续使用；停止时显示「上次使用 · 未连接」。启用系统托盘模式后，关闭主窗口只隐藏窗口，分享继续运行。

退出需要重新授权

退出当前账号会撤下分享并使此设备的当前授权失效。其他已保存账号保留，随时可切换。授权和 Funnel 权限需要在网页完成。

04

项目需要什么运行环境

静态 HTML

用 Caddy 直接预览，无需安装 Node.js 或 Python。带相对资源的页面请选择专用项目文件夹。

需要先启动的项目

按 README 和项目声明选择版本。检查 .nvmrc、.node-version、package.json、.python-version 或 pyproject.toml。 Node.js · Python

交给 AI 的运行环境提示词

请检查当前项目的 README、运行时版本文件和依赖配置，判断它需要的 Node.js、Python 或包管理器及版本。先检查我的系统已经安装了什么，只从官方来源安装缺少的兼容版本。然后按项目文档安装依赖、启动本机 HTTP 服务，验证它可以访问，并告诉我应该填入 DemoMux 的端口。如果项目没有声明版本，请先说明判断依据。

05

Windows 设置与数据目录

偏好与组件

在引导页或控制台底栏打开「设置」，选择就绪后是否打开首页、是否记住窗口大小，也可查看组件版本和数据占用。在「关闭主窗口时」选择「隐藏到系统托盘（继续分享）」即可关闭窗口后继续运行；默认仍是「退出应用（停止演示）」。

托盘图标可能位于任务栏的 ^ 折叠区域，显示位置由 Windows 管理。点击图标恢复窗口，右键可打开设置或「退出 DemoMux」。重新打开程序也会尝试唤回现有窗口。手动卸载的退出入口始终真正退出。

需要卸载时

在「设置」固定底栏点击「手动卸载 DemoMux…」。选择是否同时手动清除项目列表、本机登录和偏好，再点击「打开位置并退出 DemoMux」。外部浏览器会保留详细说明，Explorer 会定位当前程序副本并打开实际数据目录。应用完全退出后，由你选择文件送入回收站；程序不会自动删除应用或持久数据。

保留重要文件

若程序目录混放原始文件、存在修改文件或无法校验清单，不要删除整个目录，按详细说明逐项清理。选择保留时，请保留整个 Tailscale 目录和 projects-v1.json。原始 HTML、项目文件夹、其他副本和系统独立组件始终保留；不删除在线账号或云端设备记录，也不清空回收站。
