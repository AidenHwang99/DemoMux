# DemoMux Windows 首次使用

此包面向 Windows 10 22H2 和 Windows 11 的 x64 电脑，使用自包含的 .NET 桌面运行时。请解压整个 ZIP 后双击 DemoMux.exe。此内部试用包未签名，Windows SmartScreen 或公司设备策略可能拦截首次运行。 [微软的 SmartScreen 说明](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)

1. 点「启动本机预览」。首次会下载并校验 Caddy。点「打开本机预览」，在浏览器里查看内置示例。
2. 展示自己的项目时，先启动项目的本机 HTTP 服务，再在 DemoMux 填入项目端口，点「切换到此端口」。刷新预览页即可看到当前项目。「本次会话」可快速切回用过的端口。
3. 点「启用公网分享」。首次会下载并校验 Tailscale 命令行组件。点「打开授权网页」，用自己的 Tailscale 账号登录，按提示启用 Funnel。界面出现 HTTPS 地址后可复制分享。公共 DNS 首次生效可能需要几分钟。 [Tailscale Funnel 说明](https://tailscale.com/docs/features/tailscale-funnel)
4. 用完点「停止公网分享」或关闭 DemoMux。退出应用会结束本次启动的预览和隧道进程。

如果提示 8081 被占用，请在原应用中停止占用该端口的服务，再重试。如果组件下载失败，检查网络后再点对应的启动按钮。公网地址会展示当前选择的项目，请确认该项目适合公开访问。
