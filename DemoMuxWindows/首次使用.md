# DemoMux Windows 0.3.2 首次使用

面向 Windows 10 22H2 / Windows 11 x64，当前为开发验收包。解压整个 ZIP，双击 `DemoMux.exe`。自包含 .NET 和固定版本 WebView2，无需另装 .NET、Node.js、Python 或浏览器运行时。程序未签名，SmartScreen 或设备策略可能提示来源；先核实下载来源及 SHA-256。

1. 打开后依次准备 Caddy、Tailscale、登录、启用 Funnel、验证公网介绍页。首次需要联网下载固定组件并检查 SHA-256。失败可重试，取消会结束待处理操作。
2. 点击「打开授权网页」，用自己的 Tailscale 账号登录；若要求启用 Funnel，按网页提示确认。只有公网入口验证通过后才进入控制台。
3. 拖入 HTML 或点击「添加 HTML」。包含图片、CSS、JavaScript 的页面请选择「导入项目文件夹」，再选文件夹内的入口 HTML。隐藏文件和联接不进入快照。
4. 已有动态项目先按项目自己的说明启动 HTTP 服务，再「添加本机端口」。DemoMux 不启动或结束你的原项目进程。
5. 「启动」准备本机预览；「发布」选择 `/p/项目标识/` 或独立入口。路径模式下的本机端口项目必须确认基础路径配置；根路径资源可选择独立入口。任何拿到链接的人都可访问。
6. 同时最多发布三项，验证中的条目也占名额。取消一项后才能补位。首项接管公网首页，可「设为首页」，各项目链接保持。
7. 更新 HTML 后「重启」重新快照；移动源文件后「重新定位」。停止端口条目只撤下 DemoMux 转发。
8. 「使用说明」可离线打开，停止演示后仍可阅读。也可打开包内独立的 `DemoMux-Guide.html`。
9. 用完「停止全部」或关闭应用。组件不安装常驻服务或开机启动项。下次打开重新验证公网，项目由你手动发布。

项目、偏好、组件和私有授权保存在 `%LOCALAPPDATA%\DemoMux`。升级请先退出旧版，再完整解压新包。旧 `project-port.txt` 会备份为 `.pre-0.3.2.bak` 并导入项目列表；不使用系统 Tailscale 的账号。

若提示 8081 占用，请在原程序内停止对应服务后重试。公网验证失败请检查网络、DNS、HTTPS、项目基础路径和设备 Funnel 授权。「入口已验证」只表示最近一次响应头检查通过，资源、交互和外部网络仍需浏览器验收。

开发：使用 .NET 10 SDK，运行 `powershell -File DemoMuxWindows/build.ps1`；测试见 `DemoMuxWindows/Tests/README.md`。开发可通过 `DEMOMUX_DATA_DIR` 指定隔离数据目录，普通使用无需设置。
