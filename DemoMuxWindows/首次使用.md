# DemoMux Windows 0.3.5 Preview 1 首次使用

面向 Windows 10 22H2 / Windows 11 x64，当前为未签名试用版；实际覆盖见包内验收记录。将整个 ZIP 解压到本机文件夹，双击 `DemoMux.exe`。自包含 .NET 和固定版本 WebView2，无需另装 .NET、Node.js、Python 或浏览器运行时。SmartScreen 或设备策略可能提示来源；先核实下载来源及 SHA-256。

1. 打开后依次准备 Caddy、Tailscale、登录、启用 Funnel、验证公网介绍页。首次需要联网下载固定组件并检查 SHA-256。失败可重试，取消会结束待处理操作。
2. 点击「打开授权网页」，用自己的 Tailscale 账号登录；若要求启用 Funnel，按网页提示确认。只有公网入口验证通过后才进入控制台。
3. 拖入 HTML 或点击「添加项目 → 添加 HTML 文件」。包含图片、CSS、JavaScript 的页面请选择「添加项目 → 导入项目文件夹」，再选文件夹内的入口 HTML。隐藏文件和联接不进入快照。
4. 已有动态项目先按项目自己的说明启动 HTTP 服务，再「添加项目 → 连接本机端口」。DemoMux 不启动或结束你的原项目进程。
5. 「本机预览」准备并打开预览；在「发布方式」下拉框选择「按项目名发布」或「使用独立入口」。本机端口默认推荐独立入口，通常无需修改项目。选择按项目名发布时，本机服务必须支持显示的子路径，并通过本机路径检测，再点击「发布并验证」。检测失败会解释原因并提供改用独立入口；「复制项目配置路径」只复制文字，不会自动修改项目。静态 HTML 保留原来的路径／独立入口选择。任何拿到链接的人都可访问。
6. 同时最多发布三项，验证中的条目也占名额。取消一项后才能补位。首项接管公网首页，可在「更多」中「设为公网首页」，各项目链接保持。
7. 更新 HTML 后，从「更多」选择「重新启动」重新快照；移动源文件后选择「重新定位」，也可修改显示名称。停止端口条目只撤下 DemoMux 转发。
8. 「使用说明」可离线打开，停止演示后仍可阅读。也可打开包内独立的 `DemoMux-Guide.html`。
9. 用完「结束演示」或退出应用。默认关闭主窗口即退出；可在「设置 → 关闭主窗口时」改为「隐藏到系统托盘（继续分享）」，此时关闭窗口仍继续分享，点击托盘图标恢复，右键「退出 DemoMux」才真正退出。图标可能位于任务栏 ^ 折叠区域，位置由 Windows 管理。组件不安装常驻服务或开机启动项。真正退出后，下次打开重新验证公网，项目由你手动发布。

快捷键：Ctrl+O 添加 HTML，Ctrl+Shift+O 导入文件夹，Ctrl+L 添加端口，F5 复核公网，Esc 取消当前操作或关闭输入弹窗。输入有误时会在字段下方提示；账号切换、暂停或退出前会先确认。

项目、偏好、组件和私有授权保存在 `%LOCALAPPDATA%\DemoMux`。升级请先退出旧版，再完整解压新包。旧 `project-port.txt` 会备份为 `.pre-0.3.2.bak` 并导入项目列表；不使用系统 Tailscale 的账号。

若提示 8081 占用，请在原程序内停止对应服务后重试。公网验证失败请检查网络、DNS、HTTPS、项目基础路径和设备 Funnel 授权。「入口已验证」只表示最近一次响应头检查通过，资源、交互和外部网络仍需浏览器验收。

开发：使用 .NET 10 SDK 和 PowerShell 7，运行 `pwsh -File DemoMuxWindows/build.ps1`；测试见 `DemoMuxWindows/Tests/README.md`。开发可通过 `DEMOMUX_DATA_DIR` 指定隔离数据目录，`DEMOMUX_COMPONENT_CACHE` 指定固定名称 ZIP 缓存，缓存同样必须通过完整 SHA-256 校验；普通使用无需设置。

公网临时故障会自动重试，界面显示次数与下次重试倒计时。点击「停止重试」立即中止；稍后点击「重新校验」继续，无需重新登录。证书或页面标记错误需先处理原因，停止校验不代表公网入口已验证。

项目右侧「…」打开维护菜单；已发布项目的「取消发布」也位于这个菜单中。

项目图标操作从左到右为预览／打开、复制、启动／停止、发布／取消发布、更多。悬停查看中文提示；启动和发布按钮在原位置切换状态。


## 手动卸载

打开「设置 → 手动卸载 DemoMux…」，选择保留或手动清除项目列表、本机登录与偏好，再点击「打开位置并退出 DemoMux」。浏览器中的独立说明在应用退出后仍可查看；Explorer 将定位当前程序文件夹并打开实际数据位置。

请在应用完全退出后，按说明手动送入回收站。混放原始文件、包文件已修改或缺少有效清单时，不要删除整个程序目录。保留模式只清理 Components、Sessions、CaddyData、WebView2，保留整个 Tailscale 目录和 projects-v1.json。全清模式还需由你手动清理所列的本机身份和偏好文件。

始终保留原始项目、外部本机服务、其他应用副本及系统独立组件。不清空回收站、不删除在线账号或云端设备记录。临时说明文件会保留，请在读完后手动清理；应用没有自动删除功能。


## 发布前路径检查

项目标识提取项目名中的英文和数字，转为小写、短横线连接，自动建议最多 40 个字符。例如 `teleConnect_AI主动模式原型_155` → `teleconnect-ai-155`。没有英文／数字或与其他项目重名时，使用稳定的 `project-UUID`。手动编辑最多 48 字符，可点击「按项目名生成」恢复建议。

未发布且自动生成的路径随项目改名更新；自定义路径或已发布路径保持不变。已发布路径可在弹窗中按项目名重新生成，但需确认旧链接的影响；取消或发布失败不会保存新路径。新版本的独立入口发布不锁定未使用的项目路径，旧版本已锁定的路径继续保护。不修改原项目文件或基础路径配置。

本机端口项目的根路径与项目路径会在发布前检查，总体超时 8 秒。修改路径名后延迟 400 毫秒重测，旧结果立即失效；点击发布时只复用 30 秒内同一项目、端口、发布方式和路径的成功结果。预检不创建公网分享，也不占用名额。

例如本机首页正常，但 `/p/8888/` 返回 404，会在发布弹窗中说明该项目不支持此路径，阻止以该方式发布，并提供「改用独立入口」。成功只代表本机路径可访问，SPA 的资源、API、WebSocket 和交互仍需浏览器验证；最终公网校验继续保留。

公网阶段遇到项目路径 404，可从「改用独立入口…」重新打开推荐方式并再次确认；不会自动更换公开地址。发布草稿在当前应用会话内保留，未新增项目配置字段。
