- 引导页按窗口宽度切换横向五步条 / 左侧步骤栏；进度、说明和身份信息自动重排，长错误完整换行，可滚动阅读。

# DemoMux macOS 0.3.3 · Windows Preview 4 同步更新

日期：2026-11-09 · 构建号：8 · Apple 芯片 / macOS 26 · 临时签名试用版

同步基线：Windows `0.3.3-preview.4` 及主分支 `9820174`。Windows 当前代码和原有已发布版本保持原样。

## 五步准备与身份门禁

- 准备页始终展示五步，分别标记待执行、进行中、已完成、停止或需要处理；不会把跳过或未执行的步骤画作成功。
- 第一步检查 Caddy 并启动本机预览，第二步校验并启动私有 Tailscale，第三步同步账号、设备身份与域名，第四步检查 Funnel，第五步校验公网入口。
- 未同步、未登录、设备未审批及账号/设备域名变化会阻止进入公网校验；每次探测前后再次确认身份。
- 兼容旧账号缓存，但缓存不代表实际已连接，不会从缓存恢复已验证状态。

## 重试与取消

- DNS、超时、连接和握手中断按 2 / 4 / 8 / 15 秒退避，后续每次 15 秒，直到成功或用户停止。
- 证书、页面标记、跳转、HTTP 页面错误和身份错误不盲目自动重试。
- 显示尝试次数、倒计时与原因，提供停止及重新校验。第五步重试复用已完成的组件检查和登录。
- 停止准备页校验会关闭 Funnel，保留组件与账号；项目发布取消会回退该项转发并释放名额；手动复核停止后保持未验证。
- 账号命令支持及时取消。原生流光与文字更新分离，保持动画和键盘焦点，尊重减少动态效果设置。

## 界面与交互

- 直接读取 Windows 共用的 11 枚 Lucide SVG，保留固定来源、SHA-256 与完整许可，随 App 打包。
- 五个固定槽位：预览/打开、复制、启动/停止、发布/取消发布、更多。36 点按钮、18 点图标、6 点间距；状态变化不会使其他按钮跳动。
- 统一添加项目入口；次要操作收入原生暗色菜单。长名称与链接省略，提供完整提示；停用的复制按钮保留占位。
- 底栏根据会话状态切换启动或结束，窄窗口调整排列；保留 Mac 原生字体、玻璃面板和键盘访问。
- 增加项目菜单快捷键及操作取消；复制失败可重试，重新定位会撤下旧预览，端口项目支持更换来源端口。

## 平台取舍

Mac 继续使用官方 ARM64 Caddy 2.11.9 与 Tailscale 1.104.5、用户态私有实例及原有目录权限。不移植 Windows 专属 EFS 状态补丁、Windows 菜单模板或系统字体。

构建：`bash DemoMux/build.sh`。开发回归：`bash DemoMux/Tests/run.sh`。静态 HTML 和运行 App 本身仍无需 Node.js 或 Python。

完整自动回归通过；已安装应用完成五步引导、真实 HTML 公网发布及浏览器交互、撤下和退出清理。另以隔离合成窗口验证窄窗口和重试停止 / 恢复。详见 [本版验收记录](../docs/verification/macos-v0.3.3.md)；另一台干净 Mac、手机外网、重启和不同真实账号仍未覆盖。

# DemoMux macOS 0.3.2

发布日期：2026-11-07 · 版本标记：`macos-v0.3.2` · 构建号：7

适用平台：Apple 芯片、macOS 26。此版本继续作为试用版发布，使用临时签名，未经 Apple 公证。Windows 继续使用独立的 0.1.0 版本，本次功能没有同步到 Windows。

## 本次重点修复

发布较大 HTML 或网络较慢时，旧验证器要求在 6 秒内下载完整页面，可能把正文下载超时及其他入口的 HTTPS 握手中断误报为「证书可能仍在签发」。重试期间还会保留上次失败信息，账号面板混入旧的介绍页验证提示。

0.3.2 对此作出以下调整：

- 收到完整最终响应头后，校验 HTTP 状态、本次发布标记及允许的跳转目标，不等待整页下载。使用 GET，兼容不支持 HEAD 或忽略 Range 的项目。
- 公共 DNS 返回的最多四个入口并发验证，一个成功后取消其余请求，避免后一个传输错误覆盖已取得的 HTTP 诊断。
- 分别提示连接失败、响应超时、HTTPS 握手中断与证书校验错误。继续严格校验证书，不绕过 TLS，也不把本机回环或 Tailscale 私网访问当作公网成功。
- 在重新发布的身份查询之前清理旧错误、显示当前进度。失败回退或取消后释放待验证名额，本机预览保留。
- 将账号操作与项目发布的提示分开。增加「入口已验证」「正在检测公网」「公网待复核」；已发布项目复核失败时仍可重新检测、复制和打开原链接。

「入口已验证」表示最近一次入口检查通过，不是持续可用性监控。页面正文、图片、脚本及业务交互仍应在浏览器中检查。

## 相比已公开的 macOS 0.1.0

此版本汇总了此前本地开发、尚未单独发布到 GitHub 的功能：

- **同时发布最多三个项目**：HTML、带资源的项目文件夹和已经运行的本机 HTTP 端口可以混合使用。项目列表可保存超过三个条目；发布满额时需先明确取消一项。
- **两种公网入口**：支持 `/p/项目标识/` 路径；需要从根路径运行的项目可使用独立 HTTPS 入口。链接由界面生成，重复标识与旧入口复用均有检查或提示。
- **公网首页接管**：第一个项目发布后，原介绍页入口转向首页项目；可切换首页，各项目链接保持。无项目发布时恢复介绍页检查。
- **五步首次引导**：准备并校验 Caddy、准备并校验 Tailscale、登录、启用 Funnel、验证公网介绍页。组件固定版本、按需下载至应用私有目录。
- **账号管理**：显示实际连接账号和所属网络；支持添加、切换、暂停和退出。切换前撤下旧分享，切换后项目手动发布。仅管理 DemoMux 的私有 Tailscale 实例。
- **内嵌使用说明**：黑红色界面与玻璃质感组件；说明 HTML 在 App 内打开，停止服务后仍可阅读，同时提供独立的 `DemoMux-Guide.html` 供其他平台复用。
- **按需运行与清理**：应用和组件手动启动；停止或退出撤下分享。进程保护组件在应用异常退出后清理其组件进程，不停止原项目或系统已有的 Tailscale。

静态 HTML 不需要 Node.js 或 Python。已有项目仍需按自己的 README 和版本配置启动；DemoMux 只转发其 HTTP 端口。

## 安装或升级

1. 下载 `DemoMux-macOS-arm64.zip` 和同名 `.sha256` 文件，校验 ZIP 后解压。
2. 先退出旧版 DemoMux，再把新的 `DemoMux.app` 替换到「应用程序」。无需卸载 Caddy 或 Tailscale。
3. 打开应用，按界面检查连接。项目列表和账号授权保存在当前用户的应用数据目录，不在 ZIP 中；本次升级保留这些数据，项目由你手动发布。
4. 如首次打开被 macOS 拦截，请核实来源后参阅 [Apple 的官方说明](https://support.apple.com/zh-cn/102445)。受管设备可能需要管理员处理。
