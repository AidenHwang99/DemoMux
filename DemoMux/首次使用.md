# DemoMux 0.3.4 首次使用

适用于 Apple 芯片、macOS 26。解压 ZIP，把 DemoMux 拖到「应用程序」，再双击打开。试用版使用临时签名，未经 Apple 公证。如果首次打开被拦截，请先核实来源和 ZIP 的 SHA-256，再参照 Apple 的说明。受管设备可能由管理员统一限制。 [Apple 的 Mac 应用安全说明](https://support.apple.com/zh-cn/102445)

## 连接公网

DemoMux 依次检查并安装 Caddy 和 Tailscale。看到「登录 Tailscale」或「启用 Funnel」时，点击按钮，在默认浏览器完成操作。公网介绍页通过验证后进入控制台。首次 DNS 或 HTTPS 准备可能需要几分钟。若失败，按当前步骤的提示操作，再点「重试」。 [Tailscale Funnel 说明](https://tailscale.com/docs/features/tailscale-funnel)

每次手动打开应用都会启动和验证介绍页。在「设置」中关闭「公网就绪后，在默认浏览器打开首页」，可关闭自动打开浏览器。已保存的项目从控制台手动发布。若 8081 被占用，请先停止占用它的程序。

## 公网首页与应用内说明

没有项目发布时，公网入口显示介绍页，用于检查连接。第一个项目发布后，原介绍页入口和域名首页会自动转向该项目的独立链接，介绍页内容不再通过公网提供。刷新原来的入口即可打开当前首页项目。

三个项目仍保留各自完整链接，不新增发布名额。可以在已发布项目上点「设为首页」；取消首页项目后，入口自动转向剩余项目。若有项目独占 443 根入口，该项目即为首页。取消全部发布后，介绍页恢复用于连接检查；「停止全部」或退出应用会关闭整个入口。

仅启动或预览本机项目不会自动公开它；点击项目的「发布」图标并确认「发布并验证」才会接管公网入口。

「使用说明」在 App 内打开随包附带的 HTML，不需要公网、Caddy、Node.js 或 Python。停止服务后仍可阅读；菜单中的「DemoMux 使用说明」也可打开。独立的 DemoMux-Guide.html 继续交付给 Windows 端复用。

DemoMux 使用自己的 Caddy、Tailscale 配置和账号状态，无需卸载系统已有版本，也不要求 Homebrew、Node.js 或 Python。应用不会添加开机启动项。正常退出或应用异常结束后，进程保护组件会关闭 DemoMux 启动的转发组件；你的原项目和系统已有的 Tailscale 服务不由 DemoMux 停止。

## 账号与公网

控制台上方显示当前账号、登录标识、所属网络和公网状态。点「管理账号」可以添加或切换账号；首次引导和授权失败时也能打开同一个面板。

- **添加账号**：在浏览器用需要的账号完成授权。原有账号保留，项目列表共享。
- **切换并启动**：切换到已保存账号，再启动并验证该账号的 Funnel 介绍页。授权过期时会提示重新登录。所属网络不同，Funnel 权限也需要分别满足。
- **暂停演示／停止全部**：撤下分享并关闭组件，保留账号授权。下次可以继续使用。
- **退出当前账号**：撤下分享并使此设备的当前账号授权失效。再次使用需要登录；其他已保存账号不受影响。

有项目正在分享时，切换或添加账号只确认一次，面板会列出将停止的项目。退出登录也只确认一次。切换后只恢复介绍页，三个名额重新从零计算，项目由你手动发布。链接可能随账号或所属网络改变，请重新复制界面给出的完整地址。

应用停止后显示「上次使用 · 未连接」，不会为了显示账号信息持续运行后台组件。账号列表只来自 DemoMux 的私有实例；系统 Tailscale 中登录过的账号需要在 DemoMux 单独添加。浏览器当前登录的管理后台账号，不一定等于此设备实际连接的账号。

若取消新账号授权，会尝试恢复原账号选择，所有分享保持停止。登录、网络或权限失败时，可以在同一面板刷新账号、打开授权页面或重新启动 Funnel。[Tailscale 多账号说明](https://tailscale.com/docs/features/client/fast-user-switching)

## 添加并分享项目

1. 拖入一个 HTML，或点「添加项目 → 导入项目文件夹」并选择入口 HTML。项目文件夹中的普通资源会一起提供访问，请选择专用目录。修改源文件后点「更多操作 → 重新启动项目」。文件移走后可用「重新定位」恢复。
2. 转发已有项目时，先启动项目，再点「添加项目 → 连接本机端口」。可以先「本机预览」，然后「发布」。
3. 「按项目名发布」使用同域名下的 /p/项目标识/。已有项目须按界面给出的基础路径配置。使用 /assets、/api 等根路径的项目，选「使用独立入口」。同时最多发布三个项目，满额时先取消一项。独立入口重新分配时，旧链接可能指向新项目，界面会提示。
4. 从「正在分享」复制完整链接。结束时点「取消发布」「停止全部」或退出应用。本机端口项目由原启动工具管理。如果原服务停止监听，DemoMux 会撤下该项目并释放名额。重新启动原服务后，可以在 DemoMux 再次发布。

例如，项目已经在 `http://127.0.0.1:5174/` 运行，只需点「添加项目 → 连接本机端口」，填 `5174`，再点「发布」。同一窗口内可选择发布方式、检查完整地址并确认，不会再弹第二次发布确认。系统首次打开提示和 Tailscale 授权仍需按其要求处理。

## 常见情况

| 提示或现象 | 下一步 |
| --- | --- |
| 8081 已被占用 | 停止使用该端口的程序，回到向导点「重试」。不要停止不认识的进程。 |
| 下载失败或 SHA-256 校验失败 | 检查网络后点「重试」。校验失败的文件不会安装。 |
| 公共 DNS 或 HTTPS 正在准备 | 首次发布会自动重试。持续失败时检查网络是否能访问 Tailscale Funnel。 |
| 没有 Funnel 权限 | 在向导打开授权页面；组织限制下需由 tailnet 管理员授权。 |
| 页面有了，但图片或 CSS 不显示 | 带资源的 HTML 应导入专用项目文件夹；已有本机项目使用根路径资源时选择独立入口。 |
| 本机端口已关闭 | 先用原开发工具启动项目，再在 DemoMux 预览或发布。DemoMux 不会启动项目的 Node.js 或 Python 进程。 |
| 源文件失效 | 点「重新定位」选新位置，再启动或发布。已有项目标识不变。 |
| 登录状态已改变 | DemoMux 会撤下当前分享。打开「管理账号」，确认身份后重新启动 Funnel。 |
| 等待浏览器授权 | 点面板中的「打开登录页面」；如浏览器自动选择了其他账号，请在授权页面切换到需要的账号。 |

## 项目需要 Node.js 或 Python 时

单文件 HTML 和静态项目目录由 Caddy 提供，无需 Node.js 或 Python。已有项目按 README、运行时版本文件和依赖配置选版本。 [Node.js 官方下载](https://nodejs.org/en/download) · [Python 官方下载](https://www.python.org/downloads/)

> 请检查当前项目的 README、运行时版本文件和依赖配置，判断它需要的 Node.js、Python 或包管理器及版本。先检查我的系统已经安装了什么，只从官方来源安装缺少的兼容版本。然后按项目文档安装依赖、启动本机 HTTP 服务，验证它可以访问，并告诉我应该填入 DemoMux 的端口。如果项目没有声明版本，请先说明判断依据。

DemoMux-Guide.html 是独立介绍页，可在 macOS 或 Windows 浏览器离线打开。组件下载来源。 [Caddy v2.11.9](https://github.com/caddyserver/caddy/releases/tag/v2.11.9) · [Homebrew Tailscale](https://formulae.brew.sh/formula/tailscale)

## 公网验证与错误提示（0.3.2）

「入口已验证」表示当前公网首页最近一次检查通过，不表示所有项目始终可用。项目只有收到公共 DNS 入口的有效 HTTPS 响应、正确状态码和本次发布标记后，才会显示已发布。为了避免大 HTML、慢速下载或流式响应导致误判，入口验证只读取响应头，不下载完整页面；页面内容、图片、脚本及业务交互仍应在浏览器验收。

- **握手中断**：连接在 HTTPS 握手阶段中断，不能直接断言证书尚未签发。检查网络、代理或 VPN 后重试。
- **响应超时**：公网入口未及时返回响应头。检查网络或稍后重试，本机预览仍可使用。
- **证书校验未通过**：检查系统时间、代理证书和 Funnel 证书状态。DemoMux 不会忽略证书错误。
- **项目发布失败**：本次转发会回退，本机预览保留；再次点击「发布」即可重试，旧错误不会混在进行中的状态里。
- **公网待复核**：手动「重新检测公网」失败，账号可能仍连接，但公网尚未重新验证；网络恢复后点击同一按钮复核。已发布项目若复核失败，会显示「待复核」。

账号连接提示和项目发布提示分别显示。发布期间账号面板会显示当前发布进度，不会再次显示首次引导时的旧介绍页提示。取消当前步骤仍可在账号面板操作。

## 0.3.3 · 五步准备与重试

界面会一直列出五个步骤：预览引擎、连接组件、账号、Funnel、公网入口。只有实际通过的步骤才显示完成。账号未同步、设备待审批或身份发生变化时，不会进入第五步。第五步每次校验前后都会重新确认当前账号与设备域名。

DNS 尚未就绪、响应超时、连接或握手中断会自动重试，等待时间依次为 2、4、8 秒，之后每次 15 秒。界面显示尝试次数、倒计时及最近原因，并提供「停止重试」。没有固定次数上限，用户可随时停止；证书校验、页面标记、跳转、HTTP 页面错误或账号错误会停止等待处理，不会盲目重试。

- 准备阶段停止重试后，不会进入主界面或标记为公网成功；Funnel 入口关闭，保留已下载组件和账号连接。点击「重新校验」继续第五步，无需重新下载、重新登录。
- 需要彻底结束时，点击「结束准备」「结束演示」或退出应用，释放 DemoMux 自有组件。
- 项目发布期间停止重试会回退该项转发并释放名额，其他已发布项目保留。本机原服务不会被停止。
- 已完成的公开入口再次校验被停止后，显示「公网待复核」，不会继续声称本次检查通过。

倒计时只更新文字，不反复重建控件；流光采用原生动画，并尊重 macOS 的减少动态效果设置。

## 0.3.3 · 固定图标操作栏

每个项目右侧固定五个位置，从左到右为：

| 位置 | 动作 |
| --- | --- |
| 1 | 未发布时本机预览，已发布时打开网页 |
| 2 | 复制链接；未发布时保留禁用占位 |
| 3 | 启动／停止项目，原位切换 |
| 4 | 发布／取消发布，原位切换；发布校验中禁用 |
| 5 | 更多操作：重新启动、修改名称、重新定位或更换端口、校验项目、设置首页 |

图标按钮保留中文悬停说明和无障碍名称。项目名称与完整地址可通过悬停查看，长名称不会挤动右侧按钮。静态文件改动后，从更多菜单重新启动以刷新快照；更换来源会移除旧预览，下一次预览重新检查新位置。

顶部「添加项目」统一导入三种来源。底栏按当前状态只显示「启动演示」或「结束演示」，窄窗口会调整底栏排列。「使用说明」始终可以打开。

快捷键：⌘O 添加 HTML、⇧⌘O 导入文件夹、⌘L 连接端口、⌘R 检测公网。操作进行中可用 Escape 或 ⌘. 停止当前操作；系统文件选择器和确认框保留原生行为。

## 0.3.4 · 窗口缩放

引导页在较窄窗口使用横向五步条与上下排布，较宽窗口使用左步骤、右详情。详细错误可完整换行并滚动阅读；使用说明保持在底栏。

主界面在宽窗口把“正在分享”与“项目列表”并排展示，较窄时恢复上下列表。较窄项目卡片的操作图标移至下一行，顺序和尺寸不变。大窗口内容居中并限制阅读宽度，底栏独立占位；滚动到列表底部时不会被工具栏遮住。缩放不会重启组件或重置校验。

## 0.3.4 · 设置与卸载

引导页和控制台底栏都有「设置」，也可按 ⌘, 打开。设置包括：

- 公网就绪后是否自动打开首页；是否记住主窗口大小。
- 固定组件版本、下载状态和应用私有数据占用，可在 Finder 打开数据目录。
- 复制诊断摘要，包含版本与连接状态，不包含账号、项目名、源文件路径和登录链接。

点设置底栏「卸载 DemoMux…」进入同一窗口的确认页，再点「停止并卸载」。应用会结束当前任务、撤下本次分享、停止它启动的进程，将当前 App 和私有组件移到废纸篓，然后退出；不自动清空废纸篓。

默认同时清除项目列表、本机登录数据、偏好和应用缓存。取消勾选可保留这些记录，重新安装后重新下载组件即可继续使用。卸载不删除原始 HTML、项目文件夹、本机项目进程或独立安装的系统 Caddy / Tailscale，也不删除 Tailscale 在线账号；云端设备记录可在 Tailscale 管理页面自行移除。

若目录权限导致卸载失败，应用会尝试还原本次已移走的文件，显示失败项和恢复情况，保留重试入口。未能还原的文件仍在废纸篓，可在 Finder 中恢复；原位置出现的新文件不会被覆盖。卸载界面只有一次应用内确认，macOS 自身的目录权限限制仍需遵守。
