# DemoMux 首次使用

DemoMux 试用版面向 Apple 芯片的 Mac，系统要求为 macOS 26。

1. 解压 ZIP，把 DemoMux 拖到「应用程序」，然后双击打开。这个试用版使用临时签名，未经 Apple 公证。若 macOS 拦截，请先向发件人确认来源和 SHA-256，再按 Apple 的官方说明处理。公司管理的 Mac 可能由管理员统一限制。 [Apple 的 Mac 应用安全说明](https://support.apple.com/zh-cn/102445)
2. 点「安装所需组件」。应用会下载并校验 Caddy。安装完成后点「启动本机预览」，再点「打开本机预览」。看到 DemoMux 示例页就表示本机预览已启动。
3. 展示自己的项目时，先启动该项目的 HTTP 服务。把项目端口填进 DemoMux，点「切换到此端口」，再刷新预览页面。已成功使用的端口可以在「本次会话」里直接切换。点击「恢复内置示例」可回到示例页。
4. 点「启用公网分享」。DemoMux 会按需下载并校验 Tailscale。出现「打开授权网页」时，用自己的 Tailscale 账号登录。若随后提示启用 Funnel，再打开网页确认。出现 HTTPS 地址后点「复制链接」。首次启用时公共 DNS 可能需要几分钟生效。 [Tailscale Funnel 说明](https://tailscale.com/docs/features/tailscale-funnel)
5. 用完点「停止公网分享」，或直接退出 DemoMux。退出会关闭本机预览和公网分享，清空本次会话端口列表。

首次下载需要网络。若下载失败，可在界面重试。若 8081 被占用，请先停止占用它的预览服务。公网链接会将当前选择的项目分享给能访问该链接的人。

依赖下载来源。 [Caddy v2.11.9](https://github.com/caddyserver/caddy/releases/tag/v2.11.9) · [Homebrew Tailscale](https://formulae.brew.sh/formula/tailscale)
