DemoMux
使用指南 · 0.3.3
本机项目 · 公网演示

认识 DemoMux

把一个 HTML 或正在运行的本机项目，变成可以分享的 HTTPS 链接。同时发布最多三个项目。

01

请求怎么到达你的项目

  1. 来源HTML 或本机 HTTP导入静态页面，或指定已启动项目的端口。
  2. 路由Caddy提供静态文件，并把请求送到正确的项目。
  3. 公网Tailscale Funnel在你的 Tailscale 域名上提供 HTTPS 入口。
  4. 访问访客浏览器打开你分享的链接，查看对应项目。
02

准备一场演示

先验证公网介绍页

应用会按五步检查 Caddy、Tailscale、账号、Funnel 和公网入口。用自己的账号登录并启用 Funnel，公网检查通过后即可进入控制台。未同步账号不会进入公网校验。

预览，再发布

拖入单文件 HTML，或导入带资源的文件夹。项目已在本机运行时，可以直接添加 HTTP 端口。

链接用项目名区分

支持子路径的项目使用 /p/项目标识/。需要在根路径运行的项目使用独立 HTTPS 入口。

演示结束后撤下链接

可取消单个项目的发布，也可停止全部。HTML 文件有更新时，在「更多操作」中选择「重新启动项目」刷新预览内容。应用退出后，其转发组件会随之关闭。

项目接管公网首页

首个项目发布后，原介绍页入口自动转向它。可用「设为首页」更换目标，各项目链接保持不变；有项目发布时，介绍页内容不再对外提供。

说明始终在 App 内

控制台的「使用说明」打开内嵌 HTML，停止服务后仍能阅读。没有项目发布时，公网介绍页恢复用于连接检查。

03

账号与公网

看清正在使用的身份

控制台显示实际连接的 Tailscale 账号和所属网络。「管理账号」可添加、切换或重新登录，独立于系统 Tailscale。

切换后，手动选择项目

各账号共用项目列表。切换前撤下旧分享，切换后只验证介绍页；要展示哪些项目，由你决定。

暂停会保留登录

暂停演示或关闭应用会停止其转发组件。账号授权保留，下次可继续使用；停止时显示「上次使用 · 未连接」。

退出需要重新授权

退出当前账号会撤下分享并使此设备的当前授权失效。其他已保存账号保留，随时可切换。授权和 Funnel 权限需要在网页完成。

04

项目需要什么运行环境

静态 HTML

用 Caddy 直接预览，无需安装 Node.js 或 Python。带相对资源的页面请选择专用项目文件夹。

需要先启动的项目

按 README 和项目声明选择版本。检查 .nvmrc、.node-version、package.json、.python-version 或 pyproject.toml。 Node.js · Python

交给 AI 的运行环境提示词

请检查当前项目的 README、运行时版本文件和依赖配置，判断它需要的 Node.js、Python 或包管理器及版本。先检查我的系统已经安装了什么，只从官方来源安装缺少的兼容版本。然后按项目文档安装依赖、启动本机 HTTP 服务，验证它可以访问，并告诉我应该填入 DemoMux 的端口。如果项目没有声明版本，请先说明判断依据。
